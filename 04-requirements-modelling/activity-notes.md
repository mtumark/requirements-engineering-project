# Week 5 — Activity Diagram

## 1. Process Modelled
Create Booking in the College Equipment Booking System.

## 2. Purpose
To show the steps involved in creating an equipment booking and the decision that determines whether the booking can continue.

## 3. Activities
* Select Equipment
* Select Date
* Check Availability
* Enter Booking Details
* Submit Booking
* Booking Recorded

## 4. Decision and Guards
The decision is "Is equipment available?"

[available]: Continue entering and submitting the booking details.
[not available]: The process reaches an unknown that requires clarification.

## 5. Unknowns
The process for handling unavailable equipment has not been specified.

## 6. Stakeholder Question
What should happen when the requested equipment is unavailable?

## 7. Modelling Decision
I added the steps given in the instructions. I did not add a waiting list or other options because we don't know yet if the system will have these features.
