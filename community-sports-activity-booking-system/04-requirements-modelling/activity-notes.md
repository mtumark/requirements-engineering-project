# Activity Diagram

## 1. Process Modelled
Create Booking in the Community Sports & Activity Booking System.

## 2. Purpose
To show the steps involved in creating a facility booking and checking if the facility is available.

## 3. Activities
* Select Facility
* Select Date and Time
* Check Facility Availability
* Enter Booking Details
* Submit Booking

## 4. Decision and Guards
The decision is "Is the facility available?"

[available]: Continue entering and submitting the booking details.
[not available]: The process reaches an unknown that requires clarification.

## 5. Unknowns
The process for handling unavailable facilities has not been specified.

## 6. Stakeholder Question
What should happen when the selected facility is unavailable?

## 7. Modelling Decision
I used the main steps supported by the scenario. I did not add a waiting list or alternative facilities because we do not know if these features will be included.

## 8. Reflection
The diagram helped me understand the booking steps. Some details still need to be clarified.
